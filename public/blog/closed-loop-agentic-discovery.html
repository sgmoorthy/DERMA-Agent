Closed-loop discovery

Why DermaMind.ai is a research loop, not just a model

The framework is organized as a cycle of perception, knowledge grounding, execution, and validation. That closed loop is what makes the system useful for hypothesis generation rather than only prediction.

The loop

  1. Perception turns WSI context into slide-level representations.
  2. Knowledge grounding constrains search with a biomedical graph.
  3. Execution routes analysis through a sandboxed code path.
  4. Validation returns survival statistics and interpretable findings.

Why this is different

In many AI demos the workflow stops after classification. DermaMind.ai instead pushes the output into a testable research question and preserves enough metadata to inspect how the claim was produced.

Why the latest upgrade matters

The current implementation now treats discovery as an exploratory process by applying session-wide Benjamini–Hochberg FDR correction rather than relying only on raw p-values.
