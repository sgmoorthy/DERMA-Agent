Framework evolution

Scaling DermaMind.ai from skin cancer to multi-oncology discovery

DermaMind.ai began as a skin-cancer-focused pathology agent. The framework is now organized so the same perception, reasoning, and execution loop can be applied across multiple TCGA cohorts.

The key shift was architectural rather than cosmetic. The project moved from disease-specific assumptions to explicit cohort configuration, reusable data access, and shared discovery orchestration.

What changed

  • clinical data loading became cohort-aware rather than melanoma-only,
  • the discovery engine gained project-specific context,
  • the UI gained cohort-aware controls and outputs,
  • results became easier to compare across disease settings.

Why this matters

A general-purpose oncology discovery system must be able to move between cohorts without rewriting the entire workflow. That means the data layer, prompts, knowledge graph, and statistical engine all have to be parameterized rather than hardcoded.
